# Material Launcher

Лаунчер для Android в стиле Material You: настраиваемые цвета, формы иконок, папки, свободная расстановка иконок и плавные анимации запуска.

*English: a Material You style Android home launcher written in Kotlin and Jetpack Compose. Open source under the MIT license.*

## Возможности

- Динамические цвета Material You (Android 12+), светлая и тёмная темы, выбор акцентного цвета, стиль палитры и контраст
- Формы иконок, тематическая перекраска иконок, поддержка наборов иконок (Nova, ADW, Apex)
- Главный экран с настраиваемой сеткой, несколько страниц, док
- Папки разных размеров, перенос иконок жестом
- DIY-режим: иконки можно ставить в любое место экрана
- Виджеты часов и даты, добавление любых системных виджетов
- Меню приложений (шторка), быстрые действия и ярлыки приложений
- Выбор обоев
- Анимации запуска приложений и разблокировки, скорость настраивается

## Установка

Готовые APK лежат в разделе **Releases**. Скачайте `MaterialLauncher-release.apk`, установите и выберите приложение лаунчером по умолчанию.

Требуется Android 8.0 (API 26) или новее.
